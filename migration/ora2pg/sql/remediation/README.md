# Remediation folder
 
Never edit files in `output/` - they are regenerated by every export.
 
To fix a generated file:
1. Copy it here with the SAME file name (e.g. `procedure.sql`).
2. Fix it and add a header comment: issue number, what changed and why.
3. Log the issue in `docs/ora2pg-migration-report.md`, section 4.
4. Re-run `08_post_load.ps1 -StartFrom <n>` - it uses this file automatically.
 
`git diff --no-index ../../output/schema/procedures/procedure.sql procedure.sql`
shows exactly what you changed compared with the tool output
